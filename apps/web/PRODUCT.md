# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React, TypeScript, Vite and MapLibre in the existing pnpm monorepo. The independent API front owns Node, Supabase persistence, shared contracts, and the Python scientific adapter.

## Users

Brazilian growers and technical users exploring environmental evidence, with an evaluator who can complete a public example without credentials.

## Product Purpose

Make published evidence and supplied scientific results understandable through geographic context, dated series, explanations, and reproducible comparisons.

## Capabilities and Constraints

The first slice is public exploration and result inspection. Account persistence, custom analyses, and full imagery history are later frontend slices. Never imply that a retrospective municipal yield is a field forecast. Never turn water reserve into a yield/profit claim or planting instruction.

## Brand Commitments

Gaiapus branding and the supplied green/brown/ivory emblem. The latest explicit direction restores the original colorful illustrated Earth composition rather than the rejected generic dashboard alternatives. Portuguese interface copy, navy canvas, cyan selection, contextual green/amber states, and a farm landscape illustration.

## Evidence on Hand

Canonical shared publication/examples through `@gaiapus/contracts`. Local geometry from the existing prototype. Generated Earth/farm illustrations are decorative. No invented national weather reading, current sensor value, recommendation, or ownership claim is allowed.

## Accessibility & Inclusion

Keyboard-accessible search and alternatives to the map; visible focus; native modal focus handling; reduced motion; data tables; readable mobile layout; state labels alongside color.
